## 재현과 증거

```bash
python scripts/verify-complete-runtime.py \
  --env-file <격리된-테스트.env> \
  --source-auth-file <비공개-원본인증.json> \
  --source-origin <컨테이너에서-접근할-원본-origin> \
  --output <결과.json>
```

**폐기 가능한 샘플 원본 전용**입니다. 실제 원본 API에 샘플 프로젝트·정책·그룹을 생성하며,
검증 중 KODA 정책을 일시 변경한 뒤 복구하고 테스트 동기화를 비활성화합니다.
인증 파일은 `baseUrl`, `apiKey`를 포함하며 권한 `0600`으로 관리합니다. 키는 결과에 넣지 않습니다.

로컬 증거는 `output/complete-runtime-20261018/`의 `report.json`, `go-proof.json`,
`automatic-retry-proof.json`, `sync-native-proof.json`, `scheduler-proof.json`, `image-source-proof.json`, `intelligence-import-proof.json`, `restart-proof.json`,
`native-regression/runtime-report.json`, `advanced-regression.json`, `ui-report.json`입니다.
원본·인증 자료와 스크린샷은 비공개 runtime 또는 `/tmp`에 보관했고 Git에 올리지 않았습니다.
